Typography and local icons

  • M PLUS Rounded 1c, The Rounded M+ Project Authors, SIL Open Font License 1.1. Headings use local Latin subsets at weights 700 and 900, renamed Oakvx Rounded; glyph shapes and metrics are retained. Licensed under SIL OFL 1.1. Rounded-OFL.txt · Google Fonts.
  • Nunito Variable, The Nunito Project Authors, SIL Open Font License 1.1. wiiu/nunito.woff2 is used for paragraphs, navigation, buttons and supporting text in social cards. The local variable WOFF2 file preserves every glyph and the original 200–900 weight axis. Licence: wiiu/Nunito-OFL.txt. Original distribution: github.com/googlefonts/nunito.
  • Cascadia Code, Microsoft, SIL Open Font License 1.1. cascadia-code.woff2 is used for the terminal and code. The subset preserves ASCII characters, Italian accents and the punctuation in use, without changing glyph shapes, metrics or the variable axis. The derivative’s internal name is Oakvx Portfolio Mono, in keeping with the original’s reserved name. Licence: CascadiaCode-OFL.txt. Original distribution: github.com/microsoft/cascadia-code.

Avatars and animations

The five poses were supplied by the author for this portfolio and replace the personal photographs. Files are served locally from the avatars/ directory.

standing.gif, sitting.gif, dancing.gif, sleeping.gif: Original 512 × 512 px animations, with transparency and frames preserved.

showingoff.png: A static 512 × 512 px pose. The file supplied as showingoff.gif was already a PNG image; only its extension was corrected.

The *-still.webp versions contain the first frame of each GIF. They are used when animations are paused, the page is in the background or the system requests reduced motion. No external services are required.

Portfolio graphics

The menu, icons, bubbles and transitions use original CSS, SVG and JavaScript, inspired by the lightness of console menus. The pointer is the external resource documented below.

Wii U Player 1 cursor — Macrowave. Pointer from cursor.cc, labelled “Creative Commons, no attribution”. The embedded CUR is preserved unmodified; the local PNG is decoded as RGBA 32 × 32, with hotspot (7,0). Animation and integration are portfolio additions. cursor.cc · pointer-NOTICE.txt.

Avvio OAKVX / Wii. PAL 4.3E menu reconstruction with original Nintendo/Fontworks graphics, fonts and samples, local derivatives and a custom OAKVX banner. The dedicated notice records provenance, hashes and fidelity limits. NOTICE.

AFTER HOURS. DOM/Canvas interface adapted from Homebrew Channel, Team Twiizers / fail0verflow, licensed GPL-2.0-only; readable source included. Droid Sans fonts by Ascender Corporation, Apache-2.0. NOTICE · GPL-2.0 · Apache-2.0.

Original music and sounds generated by the browser.

The commit counter uses an original grid and pixel numerals drawn in code, with an edge fade inspired by Supabase’s open-source section. The data is the public GitHub commit totals for oakvx and oakvxish; no graphic assets from the reference website are used.

The journey uses an original Canvas scene: a blue wheel changes shape along a line connecting the milestones. Geometry and movement are calculated in code, without animation libraries. The avatars retain their original poses and frames.

Tiles, bars and buttons use original CSS: rounded edges, light reflections, blue-tinted shadows and small spring movements. M PLUS Rounded 1c is the heading font selected by the author; sounds are generated by the browser.

The gl. monogram, favicon and PNG social cards are original portfolio compositions. Social previews use M PLUS Rounded 1c for headings, Nunito for text and geometric shapes. The avatars appear in tiles, the desktop, contacts and footer. Console and game photos in After hours are existing editorial content.
