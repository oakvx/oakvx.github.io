Spinotto Felice.

An automotive showcase site in HTML, CSS and JavaScript. Structure and style are mine; the public version sells electric car accessories to customers who don't exist. The shop is fake, the site isn't.

Role
Original structure and style
Stack

(01) Concept

From automotive site to demo. With a serious name.

The project brings together services, approach, demo reviews, frequently asked questions and contacts in a single page with section navigation.

I created the original structure and style. Alberto Pecchini took care of cleaning up the demo, the light theme, the fictional content and the images.

The starting point: a showcase site template to reuse for any business. Spinotto Felice is made up: no purchases, no bookings, no disappointment.

(02) Process

Navigation and interactions.

  1. i.

    By sections

    Services, approach, reviews, FAQ and contacts on a single page, reachable from the menu.

  2. ii.

    Desktop and mobile

    The layout adapts to every screen. JavaScript handles the menu, the accordion FAQ and the entrance animations.

  3. iii.

    Light and dark

    The switch between light and dark themes remembers the preference in the browser. The switch above is a small tribute, and it actually works.

(03) Result

A template that can be reused for any business. Real ones too.

The demo is public and the code is on GitHub: two themes, menu, FAQ and entrance animations, on desktop and mobile.
