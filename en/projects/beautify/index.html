Beautify.

A management system for several salons: clients, services, availability and appointments share the same context. My final diploma project, in PHP and MySQL.

(01) Concept

Several salons, one management system.

Beautify manages clients, appointments, users and services for several salons. It includes public booking, inventory and analytics, with separate sections for owners and employees.

The starting point: several businesses in the same system, with data that must not mix and appointments that must not overlap.

(02) Process

How it works, from login to time slot.

  1. i.

    A salon and its users

    After login, the session identifies the active salon. Users can be linked to several salons; the owner or employee role decides which sections are accessible.

  2. ii.

    Finding a time

    The public flow selects salon, service and date. The PHP logic computes the slots considering duration, opening hours and staff capacity.

  3. iii.

    Managing the data

    The backend uses mysqli for clients, services, appointments and settings. Queries include the active salon, so each business’s data stays separate.

Server side, data side.
