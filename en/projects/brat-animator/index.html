02.1Brat Animator

Case 01 / 07Creative editor · browser2026

brat animator.

Synced lyrics, an editable timeline and Canvas rendering, in an editor that exports the video from the browser. Born as a game, now at version 5. The game got out of hand.

Application development
Stack

Languages, from GitHub

(i) Concept

From text to video, without leaving the browser. Or the chair.

I brought lyric import, LRCLIB search, timing editing, styling and export together in a single static editor.

Text and media stay in the browser: there's no server to send them to, so there's none to pay for either.

The starting point: animating text in time with music, line by line, without opening a video editor and without losing the afternoon.

(ii) Process

Three steps, from timestamp to frame.

  1. i.

    It starts from the text

    The editor imports LRC lyrics with timestamps and can search them on LRCLIB. Lines and timings stay editable.

  2. ii.

    From timing to frames

    The timeline links words and characters to time. Canvas 2D draws the text with the style and animations chosen in the editor.

  3. iii.

    Exporting the video

    WebCodecs and an MP4 muxer enable fast video-only export in compatible browsers. MediaRecorder records in real time and can include the uploaded audio.

(iii) Architecture

Four modules, each with one job.

The repository’s modules separate parsing, timing, media detection and export capability checks.

  • 01

    LRC parsing

    LRC parsing, Enhanced LRC timestamps, editable lines and project format migration.

    core.js
  • 02

    Timeline and timing

    A shared timeline for words and characters; Unicode segmentation and audio energy analysis to guide the estimates.

    timing.js
  • 03

    Media detection

    Detection of media types and of YouTube references used as previews.

    media.js
  • 04

    Browser capabilities

    WebCodecs checks for fast MP4 export: the available capabilities decide the export path.

    export.js

(iv) Result

A complete editor inside a static page. It still surprises me.

Today it’s at version 5.0, with simple and advanced editors. It reads LRC, TTML, YAML, WebVTT and SRT, and exports MP4 and WebM with no server.
