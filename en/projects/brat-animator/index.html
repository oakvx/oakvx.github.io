The project

I brought LRC import, LRCLIB search, timing edits, styling and export into a static editor. Text and media are processed in the browser.

How it works

Starting with text

The editor imports timestamped LRC lyrics and can search LRCLIB. Lines and timing remain editable.

From timing to frames

The timeline connects words and characters to time. Canvas 2D draws the text with the styling and animations selected in the editor.

Exporting video

WebCodecs and an MP4 muxer allow fast video-only export in compatible browsers. MediaRecorder provides real-time recording and can include loaded audio.

Code structure

Repository modules separate LRC parsing, timing, media recognition and export capability checks.
