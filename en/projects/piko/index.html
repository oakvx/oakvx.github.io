02.5piko

Case 05 / 07Local agent · Windows2026

piko.

An agent that uses your PC like you do, and asks before it touches anything. It looks at the app in front of it, writes a plan with a local model, waits for you to read it and only then clicks and types.

My role
Everything: backend, interface, installer
Stack
Python · FastAPI · SQLite · React · Tauri
Focus
Consent, Windows UI Automation
Project
Alpha preview · ★ 10

GitHubReleases

(01) Concept

Show me. I'll do it. After you say yes.

Most agents ask for trust up front and act in the background. piko works the other way round: no cloud, no background screen stream, no action without approval.

It reads the window through Windows UI Automation, the same information screen readers use. Screenshots only when you ask, one at a time.

The starting point: letting a model act on a real PC without handing it the keys to everything.

(02) Process

Five steps. One of them is yours.

  1. i.

    Observe

    Reads the foreground window through UI Automation.

  2. ii.

    Plan

    The local model returns a structured JSON plan.

  3. iii.

    You approve

    Nothing runs until you've read it and said yes.

  4. iv.

    Execute

    Only in the apps you granted for this session.

  5. v.

    Verify

    Checks the expected elements are there. If not, it fails out loud.

(03) Architecture

Built to be stopped.

  • 01

    Session state

    A state machine on SQLite. A session interrupted by a restart is marked failed, never resumed silently.

    Python · SQLite
  • 02

    Permissions

    Per session and per app. Password and credential windows are refused outright.

    UI Automation
  • 03

    Teach and Skills

    A consent-based, time-bounded recorder turns a demonstration into a draft Skill: versioned, with rollback. It never records typed characters.

    JSON · SQLite
  • 04

    Workfield

    The desktop interface, talking to a loopback-only, token-protected API.

    React · Tauri

(04) Result

An agent you can actually leave alone with your PC.

Every push builds a Windows installer; green builds go out as prereleases with a SHA-256 checksum, after a real UI Automation test and an install/uninstall test on hosted Windows. It's still an alpha, and the README says so first.
