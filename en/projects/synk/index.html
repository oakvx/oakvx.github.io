Case 02 / 04Conversational automationWeb application

Synk.

Synk handles the requests and appointments that arrive on WhatsApp. Behind the chat there are an intent picker, a local database, Google Calendar and a dashboard for whoever runs the business.

My role
Intent picker, backend, dashboard and fine-tuning
Stack
Node.js / PostgreSQL / llama.cpp
Focus
Conversational automation
Project
Web application

(01) Concept

People stay on WhatsApp. The rest happens behind it.

You can write in your own words, naturally: Synk recognises the reason for the message and opens the right conversation.

During the exchange it collects the details it needs before passing the request to the management system.

The starting point: requests arrive in a chat, each written in its own way, and have to become tidy appointments.

(02) Process

From the chat to the job done.

01

WhatsApp message

Someone writes to the salon. The core normalises the text, checks for duplicates and retrieves the chat context.

What are your hours on Saturday?

Can I move Thursday’s appointment?

I’d like to book a haircut.

02

Intent picker

Understands what is needed and selects the right path. Regex and custom logic work together.
