Case 06 / 07AI gateway · infrastructure2026

yag

Yet Another Gateway. One host, many models, every interface. Your servers do the inference; yag owns everything around it: authentication, routing, protocol translation, limits.

My role
Host, console and desktop client
Stack
C17 · libcurl · pthreads · React · TypeScript
Focus
Protocols, security boundaries
Project
Experimental · v0.1.0-rc.2

GitHub

Languages, from GitHub

(i) Concept

A router, a translator and a gatekeeper. Boring on purpose.

You run OpenAI-compatible servers; clients speak OpenAI, Responses or Anthropic. yag sits in the middle and makes the two ends meet.

It doesn't run models or tools, and it never will: it's the door, not the room.

The starting point: one key in front of many backends, without upstream credentials ever reaching the browser.

(ii) Architecture

One C17 binary, four jobs.

  • 01

    Authentication

    One primary key plus up to 16 extra keys, with revocable client keys and scopes. Upstream secrets stay on the host. Always.

    C17
  • 02

    Protocols

    Chat Completions passthrough, Responses to Chat, Anthropic Messages to Chat, with streaming and function tools.

    SSE · yyjson
  • 03

    Routing

    A default upstream plus up to 16 exact-model routes, with an opt-in circuit breaker for failing routes.

    libcurl
  • 04

    Limits

    1 MiB body, 16 KiB headers, 32 connections, bounded timeouts. Enforced, not suggested.

    pthreads

Console

React

Served by the host itself: status, model discovery, text chat with cancellation.

Desktop

YAG Desktop

A native chat workspace for Windows, macOS and Linux that connects to the host on the LAN with a scoped key.

Automation

GitHub Actions

Tests for host, console and desktop, CodeQL, installers for three systems, releases with SHA-256 checksums.

(iii) Result

A foundation, not a fortress. Its own words.

Codex CLI and Claude Code complete text and tool cycles against a mock backend; compatibility with real models is still unverified, there's no native TLS, and the README says not to expose it on an untrusted network.
