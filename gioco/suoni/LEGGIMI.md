# Suoni del gioco

Effetti sonori dai pacchetti di Kenney (www.kenney.nl), licenza **CC0** (pubblico dominio, nessun obbligo di citazione):
Impact Sounds, Interface Sounds, RPG Audio, Sci-fi Sounds. I file sono rinominati per uso (`passo-cemento-1.ogg`, `porta-apre-2.ogg`, …);
`elenco.json` dice quali file ha ogni suono. Il gioco sceglie a caso tra le varianti e varia un po' l'intonazione.
Se un file manca, il gioco usa il vecchio suono generato. La musica liminale resta generata dal codice (`js/musica.js`).
