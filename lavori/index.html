02Tutti i lavori

(02) Tutti i lavoriCasi studio, strumenti, ricerca

Tutto quello che ho fatto. Anche le cose piccole.

In ordine di peso, non di data. Per ognuno: cos’è, su cosa gira e quanto è davvero finito.

(i) Casi studio

Quelli con una pagina tutta loro.

  • Node.js · PHP · PostgreSQL — release candidatesynkPrenotazioni on-premise per saloni: WhatsApp, Google Calendar e un database che non sovrappone mai due appuntamenti.
  • C17 · React · TypeScript — sperimentaleyagUn gateway AI: una chiave davanti a tanti modelli, con traduzione fra OpenAI, Responses e Anthropic.
  • Python · React · Tauri — alpha, ★ 10pikoUn agente per Windows con un modello locale: niente si muove senza il tuo sì.
  • JavaScript · Canvas · WebCodecs — v5, ★ 4Brat AnimatorUno studio di lyric video che vive nella scheda del browser. Niente backend, niente upload.
  • C · Python — ricerca, v0.17middleManPS4Un laboratorio di ricerca su PS4 dove ogni affermazione porta un’etichetta: provato, non provato, non implementato.
  • PHP · MySQL — progetto di diploma, ★ 2BeautifyUn gestionale per più saloni. L’antenato di synk.
  • HTML · CSS · JavaScript — demo pubblicaSpinotto FeliceUn modello di sito vetrina, provato su un negozio inventato.
