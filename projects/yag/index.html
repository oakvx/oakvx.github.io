02.6yag

Caso 06 / 07Gateway AI · infrastruttura2026

yag

Yet Another Gateway. Un host, tanti modelli, ogni interfaccia. I tuoi server fanno l’inferenza; yag si occupa di tutto il resto: autenticazione, instradamento, traduzione dei protocolli, limiti.

Il mio ruolo
Host, console e client desktop
Stack
C17 · libcurl · pthreads · React · TypeScript
Focus
Protocolli, confini di sicurezza
Progetto
Sperimentale · v0.1.0-rc.2

GitHub

Linguaggi, da GitHub

(i) Concept

Un router, un traduttore e un buttafuori. Noioso di proposito.

Tu hai server compatibili OpenAI; i client parlano OpenAI, Responses o Anthropic. yag sta in mezzo e fa incontrare le due parti.

Non esegue modelli e non esegue strumenti, e non lo farà mai: fa da porta, non da stanza.

Il punto di partenza: una chiave davanti a tanti backend, senza che le credenziali dei server arrivino mai al browser.

(ii) Architettura

Un binario C17, quattro lavori.

  • 01

    Autenticazione

    Una chiave principale più fino a 16 aggiuntive, con chiavi client revocabili e permessi. I segreti dei server restano sull’host. Sempre.

    C17
  • 02

    Protocolli

    Chat Completions passante, Responses verso Chat, Anthropic Messages verso Chat, con streaming e strumenti.

    SSE · yyjson
  • 03

    Instradamento

    Un server di default più fino a 16 rotte per modello, con un interruttore automatico opzionale per le rotte che falliscono.

    libcurl
  • 04

    Limiti

    Corpo da 1 MiB, intestazioni da 16 KiB, 32 connessioni, timeout limitati. Imposti, non suggeriti.

    pthreads

Console

React

Servita dall’host stesso: stato, elenco dei modelli, chat testuale annullabile.

Desktop

YAG Desktop

Uno spazio di chat nativo per Windows, macOS e Linux che si collega all’host in rete locale con una chiave limitata.

Automazione

GitHub Actions

Test di host, console e desktop, CodeQL, installer per tre sistemi, release con checksum SHA-256.

(iii) Risultato

Una base, non una fortezza. Parole sue.

Codex CLI e Claude Code completano scambi di testo e strumenti contro un backend simulato; la compatibilità con modelli veri non è ancora verificata, non c’è TLS nativo, e il README dice di non esporlo su una rete non fidata.
